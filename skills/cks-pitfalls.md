## 一句话结论

CKS32 是 STM32 的**寄存器级兼容克隆**：硬件 Pin-to-Pin 替换，ST 标准库/HAL 库零修改（F103）或少量修改（F105）可跑。优势：价格低约 30%、功耗低约 10mA、国产供货稳定。内存地址映射、寄存器位定义与 ST 一致——这是软件零修改的关键。

## 🔴 不兼容项（会翻车，必防）

### GPIO_PinRemapConfig() 重映射函数会关闭调试口

- 函数体 `tmpreg |= BGAFR_SWJCFG_MASK;` 会把 **SWD/JTAG 调试口关掉** → 芯片断连，无法再调试/烧录
- 解法（二选一）：
  1. 新建 `CKS_GPIO_PinRemapConfig()`：复制函数体并**注释掉 `BGAFR_SWJCFG_MASK` 相关两处代码**，替换所有调用点；
  2. 直接用中科芯官方库
- 速记：**「一跑重映射就掉调试口」→ CKS 的锅**

## 🟡 注意项（5 条，F103/F105 通用）

| # | 现象 | 解法 |
|---|------|------|
| 1 | 访问非法内存地址触发 **HardFault**（ST 是静默忽略） | 防野指针/越界访问；速记：**「访问野地址就 HardFault」→ CKS 的锅** |
| 2 | 双 ADC 外部触发模式下从 ADC 产生多余转换 | 主 ADC 外部触发时，从 ADC 设为软件触发 |
| 3 | SPI / Timer 复用口不支持开漏输出 | 外部加电平转换 / 3 态转换芯片 |
| 4 | 部分烧录器报 ID 错误无法烧写 | 用中科芯推荐烧录工具；ST-Link / J-Link 大多可用 |
| 5 | BOOT0 上拉电阻 >15kΩ 导致启动方式失效（内部下拉约 40kΩ，外部 100kΩ 盖不住） | 上拉电阻 ≤15kΩ |

## 🟠 F105（互联型）特有注意

- **定位别混用**：F105 = 双 CAN + USB OTG FS 的 Connectivity line，与 F103 普通型定位不同；只用单 CAN + 简单外设的项目无需上 F105
- **双 CAN 是核心价值**：CAN1 + CAN2 的寄存器行为建议上板验证（中科芯称寄存器级兼容）
- **USB OTG**：建议用中科芯官方 USB 库，避免 HAL 差异
- LQFP64 外设多 → **引脚复用冲突仔细核对**（复用功能多，容易撞脚）
- 主频以中科芯官方手册 **72MHz** 为准（个别平台标 144MHz 存疑）

## ⚪ 其他潜在差异

- Flash 擦写寿命、ADC 模拟精度可能有偏差
- Keil 无 CKS 官方 Device Pack → 用 STM32F103/F105 对应包即可
- 关键项目需**小批量功能验证 + 电气参数比对 + 长期可靠性测试**

## 开发流程（和用 ST 原片完全一致）

```
CubeMX 选 STM32F103C8 / STM32F105RE（库里没有 CKS 器件，选对应 ST 型号生成）
   → 时钟树 / 引脚 / 外设照常配置
   → Keil 用 ST 对应器件编译（或用中科芯 Pack）
   → ST-Link + SWD 烧录 / 调试（OpenOCD st 分支通用）
   → 烧进 CKS32 运行 ✅
```
