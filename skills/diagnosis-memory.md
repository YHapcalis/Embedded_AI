# 内存问题诊断

> ⚠️ 渐进式披露：仅在 SKILL.md 路由到本技能时读取（按需单读）。

> 来源：改编自 AixProbe 技能包（CC BY-NC-SA 4.0，非商用）
> 适配：foundation 工具接口（MCP 风格）

## 适用场景

- 栈溢出（Stack Overflow）
- 堆溢出 / malloc 失败
- 内存踩踏（变量莫名被改）
- 程序运行一段时间后行为异常
- RTOS 任务栈不够

## 第 1 步：栈溢出检测

### 检查当前 SP

```
→ halt()
→ register_read("sp")
← {value: "0x20000120"}
```

对照芯片内存布局（从 chip-reference.md 获取）：

| 芯片 | SRAM 起始 | SRAM 大小 | 栈通常在高地址 |
|------|---------|---------|---------------|
| STM32F103C8 | 0x20000000 | 20KB | SP 初始=0x20005000 |
| STM32F407VG | 0x20000000 | 128KB+64KB | SP 初始=0x20020000 |
| ESP32-C3 | 0x3FC80000 | 400KB | 栈在 SRAM 高区 |

**判断**：
- SP 接近 SRAM 起始地址 → 栈几乎耗尽
- SP 低于 .bss 段末尾 → 栈已溢出到全局变量区

### 检查栈 canary（如果启用）

很多 RTOS 在栈底放 magic 值（如 0xA5A5A5A5），栈溢出时会覆盖：

```
// 读取栈底区域（SRAM 起始+少量偏移）
→ memory_read(0x20000000, 16)
// 如果出现大量相同值（0xA5A5A5A5）后突然变为其他数据
// → 溢出边界在此处
```

### 向量表检查（栈溢出严重时）

```
// 读 VTOR（向量表偏移寄存器）
→ memory_read(0xE000ED08, 1)
// 如果 VTOR 指向 SRAM，检查向量表内容是否被破坏
```

## 第 2 步：堆状态检查

### FreeRTOS 堆

```
// FreeRTOS 全局变量（地址从 map 文件获取）
// xFreeBytesRemaining — 剩余堆空间
// xMinimumEverFreeBytesRemaining — 历史最小剩余
```

### 通用 malloc 堆

堆通常在 .bss 段之后、栈之前。堆管理器内部数据结构被破坏时：
- malloc 返回 NULL
- free 后程序崩溃（双重释放/野指针释放）

## 第 3 步：内存踩踏定位

### 方法 1：断点监控

在怀疑被踩踏的地址设硬件监视断点（DWT watchpoint）：

```
// 设置数据断点（DWT watchpoint）
→ 写 DWT_COMPx / DWT_FUNCTIONx 寄存器
// 当目标地址被写入时自动断下
→ resume()
// 等待触发...
→ register_read("pc")
// PC 指向执行写操作的指令
```

### 方法 2：内存填充 + 对比

```
// 在关键区域填充 pattern
→ memory_write(addr, 0xDEADDEAD)

→ resume()
// 运行一段时间后
→ halt()

// 重新读取，看哪些位置被修改
→ memory_read(addr, 4)
```

## 第 4 步：RTOS 任务栈检查

### FreeRTOS 任务栈水印

FreeRTOS 的每个任务栈在创建时会填充 0xA5。
`uxTaskGetStackHighWaterMark` 返回剩余最小值。

通过调试器手动检查：
```
// 读取 pxCurrentTCB（当前任务控制块）
// TCB 结构中包含 pxStack（栈底指针）

// 从栈底向上扫描，找第一个非 0xA5A5A5A5 的位置
→ memory_read(栈底地址, 64)
// 连续的 0xA5 区域大小 = 未使用的栈空间
```

## 内存布局参考

典型嵌入式内存布局（低地址→高地址）：

```
0x20000000 ┌──────────────────┐
           │ .data (初始化全局) │
           ├──────────────────┤
           │ .bss  (零初始化)  │
           ├──────────────────┤
           │ Heap  ↓ 向上增长  │
           │                  │
           │   (空闲区域)      │
           │                  │
           │ Stack ↑ 向下增长  │
0x20005000 └──────────────────┘ ← 初始 SP
```

栈和堆相向增长，当它们相遇时 → 栈溢出或堆溢出。
