# 外设工作状态诊断

> 来源：改编自 AixProbe 技能包（CC BY-NC-SA 4.0，非商用）
> 适配：foundation 工具接口（MCP 风格）

## 适用场景

- GPIO 输出不对 / LED 不亮不灭
- 串口收发异常 / 无数据
- SPI/I2C 通信失败
- 定时器不触发 / 频率不对
- ADC 读数异常 / 恒为 0
- PWM 无输出

## 核心策略

外设不工作的排查顺序（从底层到顶层）：

```
1. 时钟使能了吗？  → 读 RCC 使能寄存器
2. GPIO 配置对吗？  → 读 GPIO 模式/复用寄存器
3. 外设自身使能了吗？→ 读外设 CR 的 Enable 位
4. 参数对吗？      → 读波特率/分频/模式
5. 中断配了吗？    → 读 NVIC 和外设中断使能
6. 有硬件问题吗？  → 数据通道验证外部信号
```

## 通用诊断：时钟检查

**所有外设问题首先检查时钟！未使能时钟，外设寄存器读出全 0。**

需要从 SVD 中查找芯片的 RCC 外设寄存器地址。常见 STM32F4 地址：

```
→ halt()

// AHB1 外设时钟使能（GPIOA/B/C/D...）
→ memory_read(0x40023830, 1)   // RCC_AHB1ENR

// APB1 外设时钟使能（TIM2-7, USART2/3, SPI2/3, I2C1-3, CAN, UART4/5...）
→ memory_read(0x40023840, 1)   // RCC_APB1ENR

// APB2 外设时钟使能（USART1/6, SPI1, TIM1/8/9/10/11, ADC...）
→ memory_read(0x40023844, 1)   // RCC_APB2ENR
```

## GPIO 诊断（F4 系列）

```
// GPIOA 基地址 = 0x40020000（GPIOB=0x40020400, GPIOC=0x40020800...）

→ memory_read(0x40020000, 1)   // MODER (引脚方向)
→ memory_read(0x40020008, 1)   // ODR   (输出值)
→ memory_read(0x40020010, 1)   // IDR   (输入值)
→ memory_read(0x40020020, 1)   // AFR[0] (复用功能, 低 8 脚)
→ memory_read(0x40020024, 1)   // AFR[1] (复用功能, 高 8 脚)
```

**判断要点**：
- MODER=0b00 → 输入；0b01 → 输出；0b10 → 复用；0b11 → 模拟
- 复用外设时 AFR 必须配置正确（如 USART1 TX=PA9 → AF7）
- ODR 写 1 但 IDR 读 0 → 外部短路/引脚被拉低

## 串口诊断（USART）

```
// USART1 基地址 = 0x40011000

→ memory_read(0x40011000, 1)   // SR   (状态)
→ memory_read(0x4001100C, 1)   // BRR  (波特率)
→ memory_read(0x40011010, 1)   // CR1  (使能位 UE/TE/RE)
→ memory_read(0x40011014, 1)   // CR2  (停止位)
→ memory_read(0x40011020, 1)   // DR   (数据)
```

**判断要点**：
- UE[13] / TE[3] / RE[2] 必须 = 1
- 波特率 = fck / (16 * BRR)，算出来和期望对比
- TXE[7] 置位 = 发送寄存器空（可发下个字节）
- RXNE[5] 置位 = 收到数据
